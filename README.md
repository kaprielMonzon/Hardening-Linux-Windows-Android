# 🐧🪟🤖 Hardening de Linux Windows y Android 

En este repositorio encontraran, metodologias, practicas y herramientas para mejorar la seguridad de nuestros dispositivos, muy importante en estos dias donde todo esta conectado a la red, donde cualquier cosa puede fallar, dejar un hueco a cualquier persona indeseada.



## ⚠️ Cosas a tener en cuenta

No existe la seguridad definitiva, podemos pasar un sistema inseguro a uno mas seguro, pero no perfecto, teniendo todo lo de esta guia instalado y configurado en cada dispositivo como se indica, hay factores que se nos escapa como usuarios. Las actualizaciones de seguridad que pueden tardar, alguna mala configuracion que hayamos echo, si nos queremos tomar en serio la seguridad 
tendremos que estar en alerta con las brechas y filtraciones de seguridad de los productos tecnologicos que usemos de corporaciones como Google, Microsoft, etc. Sobre todo con los proyectos de codigo abierto en sus respectivos puntos de reunion, como GitHub.
